📊 Prompt 结构预览
═══════════════════════════════════════════════════════════════════

阶段1: 理解问题 (4步)
  └─ 阅读 issue → 理解本质 → 识别代码区域 → 总结原因

阶段2: 环境准备 (4步)
  └─ 克隆仓库 → 查看结构 → 定位文件 → 检查测试

阶段3: 问题诊断 (4步)
  └─ 阅读代码 → 重现问题 → 确认bug → 分析原因

阶段4: 设计修复方案 (4步)
  └─ 提出方案 → 评估优缺点 → 选择方案 → 考虑副作用

阶段5: 实施修复 (4步)
  └─ 修改代码 → 保持风格 → 添加注释 → 展示diff

阶段6: 验证修复 (4步)
  └─ 更新测试 → 运行测试 → 检查回归 → 调整修复

阶段7: 生成交付物 (3步)
  └─ 生成补丁 → 写commit msg → 总结修复

阶段8: 最终报告 (1步)
  └─ 生成完整报告（分析+方案+变更+测试+风险）
