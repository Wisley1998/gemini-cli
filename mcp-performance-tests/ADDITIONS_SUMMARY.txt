   📦 命令: uvx mcp-run-python@latest stdio

   📝 测试: 单页抓取、HTML返回、批量抓取

## ⚙️ 依赖要求

### Pydantic Run Python 需要:
✓ Python (已安装 ✅)
✓ Deno (需要安装)
  → brew install deno
✓ uvx (需要安装)
  → pip install uv

### Fetcher MCP 需要:
✓ Node.js (已安装 ✅)
✓ Playwright Chromium (首次运行时安装)
  → npx playwright install chromium

      "env": {}
    },

      "args": ["-y", "fetcher-mcp"],
