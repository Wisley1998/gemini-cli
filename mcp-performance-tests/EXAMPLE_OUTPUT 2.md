## 输出解读

### 时间分布

- **启动耗时 (3333ms)**: Docker 容器启动和 MCP server 初始化
- **握手耗时 (222ms)**: MCP 协议初始化和能力协商
- **工具列表 (111ms)**: 获取所有可用工具的元数据
- **首次执行 (2334ms)**: 第一次调用工具（包含冷启动）
- **二次执行 (1666ms)**: 第二次调用相同工具（缓存生效）
- **关闭耗时 (50ms)**: 清理资源和断开连接

### 性能提升

- 二次执行比首次快 28.6%，说明缓存机制有效

### 总耗时

- **8950ms** (约9秒) - 完整的端到端测试时间

## 注意事项

1. **首次运行会更慢**: 需要下载 Docker 镜像、npm 包等
2. **网络影响**: API 调用时间受网络速度影响
3. **机器性能**: CPU/内存/磁盘速度会影响结果
4. **Docker 开销**: GitHub MCP 使用 Docker，启动时间较长
5. **模型大小**: Huggingface 测试的模型越大，耗时越长
