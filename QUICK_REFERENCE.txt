🚀 快速开始
═══════════════════════════════════════════════════════════════════

方式1: 一键配置
  ./setup-swe-bench-tools.sh

方式2: 手动添加
  gemini mcp add git npx -y @modelcontextprotocol/server-git
  gemini mcp add filesystem npx -y @modelcontextprotocol/server-filesystem

验证安装:
  gemini mcp list

运行测试:
  ./test-simple-swe-bench.sh


📝 典型使用流程
═══════════════════════════════════════════════════════════════════

gemini --yolo "
处理这个SWE-bench任务:
1. 克隆 https://github.com/user/repo
2. 切换到 commit abc123
3. 阅读并理解 issue #456
4. 定位并修复bug
5. 运行测试验证
6. 生成补丁
"

工具调用顺序:
  git_clone → git_checkout → read_file → search_file_content
  → write_file → run_shell_command → git_diff
