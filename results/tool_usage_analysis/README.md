# 工具使用分析报告

## 📊 概述

本文件夹包含对 benchmark 测试结果的详细工具使用分析。分析脚本会解析所有的 `*_summary.txt` 文件,统计各个工具的使用情况、执行时间和性能数据。

## 📁 文件说明

### 📄 文本报告

- **`deep_research_report.txt`** - Deep Research 任务的详细统计报告
- **`code_report.txt`** - Code 任务的详细统计报告

报告包含:

- 总体统计(任务数、总时间、成功率等)
- 平均统计(平均执行时间、API 时间、工具时间等)
- 工具使用统计(使用次数、总时间、平均时间、最小/最大时间)
- MCP 服务器使用统计
- 模型使用统计(请求次数、token 消耗)

### 📈 可视化图表

每种任务类型生成 5 个图表:

#### 1. `*_01_tool_usage_time.png` - 工具使用时间排名

- 横向条形图,显示各工具的总使用时间
- 按时间降序排列,显示前 15 个工具
- 适合识别最耗时的工具

#### 2. `*_02_tool_usage_count.png` - 工具使用频率

- 横向条形图,显示各工具的调用次数
- 按频率降序排列,显示前 15 个工具
- 适合识别最常用的工具

#### 3. `*_03_mcp_usage.png` - MCP 服务器统计

- 双图对比:总时间 vs 使用次数
- 显示所有 MCP 服务器的使用情况
- 适合分析 MCP 服务器的性能开销

#### 4. `*_04_distributions.png` - 时间分布饼图

- 4 个饼图组合:
  - API vs 工具时间分布
  - Top 5 工具时间分布
  - MCP 服务器时间分布
  - 模型 Token 使用分布
- 适合快速了解时间开销的分布情况

#### 5. `*_05_tool_avg_time.png` - 工具平均执行时间

- 横向条形图,显示各工具的平均执行时间
- 按平均时间降序排列,显示前 15 个工具
- 适合识别单次执行最慢的工具

## 🚀 使用方法

### 运行分析脚本

```bash
cd /Users/suiyifan/Desktop/multi-agnets/gemini-cli/results
python3 analyze_tool_usage.py
```

脚本会自动:

1. 扫描 `deep_research/` 和 `code/` 目录中的所有 `*_summary.txt` 文件
2. 解析性能数据和工具使用情况
3. 生成统计报告并输出到控制台
4. 将文本报告保存到 `tool_usage_analysis/` 文件夹
5. 生成可视化图表并保存到 `tool_usage_analysis/` 文件夹

### 分析结果的应用

1. **性能优化**: 识别最耗时的工具,优先优化这些工具的性能
2. **资源分配**: 根据工具使用频率和时间,合理分配系统资源
3. **架构改进**: 分析 MCP 服务器的开销,优化初始化和通信策略
4. **成本控制**: 监控模型 API 的 token 消耗,优化提示词策略

## 🔧 自定义分析

如需修改分析脚本以适应特定需求:

1. **添加新的统计维度**: 在 `parse_summary_file()` 函数中添加解析逻辑
2. **修改图表样式**: 在 `create_visualizations()` 函数中调整 matplotlib 参数
3. **添加新的图表**: 在 `create_visualizations()` 函数中创建新的子图
4. **过滤特定工具**: 在 `aggregate_statistics()` 函数中添加过滤条件
